# Age Gracefully

A modern retirement planning app for modeling dreams, savings, and future life goals.

## Features

- Retirement plan calculator
- Scenario presets (conservative, balanced, aggressive)
- Savings projection visualization
- Personalized insight summary
- Local persistence in the browser
- Responsive dark-mode dashboard

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Tech stack

- Next.js
- TypeScript
- Tailwind CSS
- Recharts

## Project goal

Age Gracefully helps people clarify how much they need to save and how different choices affect their retirement lifestyle.
